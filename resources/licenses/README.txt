Third-party licence texts - StringScale Tuner preview

LGPL-3.0-only.txt and GPL-3.0-only.txt: the LGPL v3 supplements GPL v3;
both texts are included for the dynamically linked open-source Qt libraries.
LGPL-2.1-FFmpeg.txt: LGPL v2.1 text from FFmpeg's upstream source tree.
SOURCES.json records the exact upstream text URLs and SHA256 checksums.
It identifies the text's provenance, not the exact FFmpeg binary version.

QT-THIRD-PARTY-NOTICES.txt: attributions and licence texts extracted from
the versioned Qt source modules.
FFmpeg-LICENSE.md: upstream FFmpeg 7.1 licence and attribution information.
RUNTIME_SOURCES.json: archive URLs and SHA256 values for Qt and FFmpeg sources.
RUNTIME_LIBRARY_REPLACEMENT.md: steps for using modified runtime libraries.

The matching source bundle should accompany the public installers on the
project's Releases page. See THIRD_PARTY_NOTICES.md for component details.
