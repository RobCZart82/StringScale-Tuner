# StringScale Tuner – szerzői arculati elemek

Robert által 2026-11-03-án átadott eredeti SVG-források a
Névjegy / About ablakhoz.

| Fájl | Használat |

| [GYR-black.svg](GYR-black.svg) | Sötét logó világos témához |
| [GYR-light.svg](GYR-light.svg) | Világos logó sötét témához |

| [Alairas-Vektor-light.svg](Alairas-Vektor-light.svg) | Világos szignó sötét témához, átlátszó háttérrel |

A fájlok vektoros útvonalakat tartalmaznak, beágyazott raszterkép,
betűkészlet-igény és külső hivatkozás nélkül. Az eredeti SVG-ket meg kell őrizni.
Az eredeti képarány és viewBox alapján méretezendők; a nem nulla viewBox
kezdőkoordináták nem hagyhatók figyelmen kívül. Kis méretben a finom vonások
olvashatóságát, nagy DPI-n az élességet külön is ellenőrizni kell.

A világos szignó az eredetiből kizárólag a kitöltőszín cseréjével készült
(#211A19 → #eee9dc), a világos logó színéhez igazodva. A Bézier-görbék,
a viewBox, a méretek és az átlátszó háttér változatlanok. A Névjegy a témához
illő szignót használja; sötét témában sincs külön világos háttérpanel.

A fogaskerék-menüben a Névjegy / About a Beállítások / Settings
és Hang / Audio elemek alatt érhető el.
Részletes követelmények: [fejlesztési ütemterv](../../docs/ROADMAP.md).
