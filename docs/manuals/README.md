# User manuals

Two 8-page colour PDF manuals for 0.2.0-alpha.1, in Hungarian and English.
They cover Windows EXE/macOS PKG installation, current ZIP previews, input/channel
selection, the three displays, standard/Drop D tuning, themes/languages and support.

The manuals distinguish the native installers from the developer ZIP and explain
pitch recovery after digital clipping. System prompts vary by OS version. Screenshots are application-rendered
previews, without live microphone input. No proprietary operating-system screenshots
are reproduced. The original logo/signature are the project owner's supplied assets.

Manuals are copied to every preview stage under manuals/. Installers retain them.
On macOS they are in Applications/StringScale Tuner Documents/manuals; Windows
adds Start menu links. Native installer scope and testing are in [the installer guide](https://github.com/RobCZart82/StringScale-Tuner/blob/main/docs/INSTALLERS.md).
