StringScale Tuner 0.2.0-alpha.1
MAGYAR / ENGLISH

MAGYAR

Ingyenes, önálló gitár- és basszushangoló Windows x64 és macOS Apple Silicon
rendszerekhez. A magyar és angol, képes PDF-kézikönyvet a manuals mappában találod.

Indítás: Windows alatt a Start menüből; macOS-en az Alkalmazások mappából.
Válaszd ki az audiointerfészt, a megfelelő bemeneti csatornát és a hangolási
profilt. Egyszerre egy húrt pengess meg. A fogaskerék Beállítások pontjában
nyelvet, világos/sötét témát és felületméretet választhatsz.

A szoftver és a teszttelepítők nem kapnak kiadói tanúsítványt/notarizációt.
Az első indítás biztonsági engedélyezését a PDF-kézikönyv mutatja be.
macOS-en a mikrofonhozzáférést külön engedélyezni kell.

TELEPÍTÉSI JÓVÁHAGYÁS

Windows
1. Nyisd meg a hivatalos kiadásból letöltött EXE-t.
2. Ismeretlen program SmartScreen-figyelmeztetésénél:
   További információ > Futtatás mindenképpen, ha elérhető.
3. Fejezd be a telepítőt, majd indítsd a programot a Start menüből.

macOS
1. Nyisd meg a PKG-t, és zárd be az ismeretlen fejlesztő miatti figyelmeztetést.
2. Apple menü > Rendszerbeállítások > Adatvédelem és biztonság > Biztonság.
3. A blokkolt fájlnál: Megnyitás mindenképpen, majd hitelesítés és megerősítés.
4. Telepíts, majd indítsd a StringScaleTunert az Alkalmazásokból.
5. Az app külön blokkolásánál ismételd meg a 2-3. lépést. Engedélyezd a mikrofont.

Kártevőriasztás, karantén vagy sérült fájl esetén tölts le friss példányt,
ellenőrizd a SHA256-ot, és jelezd a hibát. A rendszerszintű védelem maradjon
bekapcsolva. Felügyelt gép tiltásánál kérd a rendszergazda segítségét.


ENGLISH

Free standalone guitar and bass tuner for Windows x64 and macOS Apple Silicon.
Illustrated Hungarian and English PDF user manuals are in the manuals folder.

Launch from the Windows Start menu or macOS Applications. Select your audio
interface, input channel and tuning profile. Pluck one string at a time.
The gear > Settings menu offers language, light/dark appearance and UI size.

The app/test installers have no publisher certificate or notarization.
See the PDF manual for first-launch security prompts. On macOS, microphone
permission must also be granted.

INSTALLATION APPROVAL

Windows
1. Open the EXE downloaded from the official release.
2. For an unrecognized-app SmartScreen warning:
   More info > Run anyway, if offered.
3. Complete setup, then launch the app from the Start menu.

macOS
1. Open the PKG and dismiss the unidentified-developer warning.
2. Apple menu > System Settings > Privacy & Security > Security.
3. For the blocked file, choose Open Anyway, authenticate and confirm.
4. Complete installation, then launch StringScaleTuner from Applications.
5. If the app is separately blocked, repeat steps 2-3. Allow microphone access.

For malware, quarantine or damaged-file alerts, download a fresh official copy,
check SHA256 and report the problem. Keep system-wide protections enabled.
For an administrator policy block, ask your administrator.
